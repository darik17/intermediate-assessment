# intermediate-assessment

Промежуточная аттестация для курса Инженер-архитектор в сфере искуственного интелекта. 
Обработка данных из https://github.com/irlcode/RFSD

Репозиторий находится: https://github.com/darik17/intermediate-assessment

## Что сделано

1. Скачан и прочитан локальный Parquet-файл RFSD и изучены его размеры и список колонок.
2. Выбраны 20 колонок и первые 1000 строк; результат сохранён в CSV и Parquet.
3. Проведён базовый анализ: изучены типы данных, пропуски и описательная статистика.
4. Рассмотрены категории, признаки отчётности, секции ОКВЭД и распределение по регионам.
5. Рассчитана матрица корреляции для числовых колонок.
6. Построены гистограммы выручки, чистой прибыли и активов; найдены выбросы. Описаны выводы для этих трех колонок. 
7. Построена матрица корреляции для 20 колонок и описаны связи. Описана интерпретация корреляций.
8. Построена диаграмма рассеивания между выручкой и себестоимостью и сделан вывод об их связи.
